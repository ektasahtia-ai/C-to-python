# C to Python Code Conversion

## 📌 About the Project

This repository contains basic Python programs, including conversions of programming concepts from C to Python. It is designed to help beginners understand Python syntax, logic, and data structures.

## 📂 Programs Included

### 1. Factorial

Calculates the factorial of a non-negative integer using a loop.

**Example:**

* Input: `5`
* Output: `120`

**Concepts Used:** Loops, functions, and conditional statements.

### 2. Fibonacci Series

Prints a specified number of terms in the Fibonacci sequence.

**Example:**

* Input: `7`
* Output: `0 1 1 2 3 5 8`

**Concepts Used:** Variables, loops, and arithmetic operations.

### 3. Student Details Using a Dictionary

Stores and displays student information using a Python dictionary.

**Example Output:**

```text
Name: Rahul
Roll: 101
Marks: 87.5
```

**Concepts Used:**

* Dictionaries
* Key-value pairs
* Accessing dictionary values
* F-strings for formatted output

## 🛠️ Technologies Used

* **C** — Original programming language for code conversion.
* **Python** — Used for the implementations.

## ▶️ How to Run

1. Install Python on your computer.
2. Clone the repository:

   ```bash
   git clone <repository-url>
   ```
3. Open the repository folder.
4. Run the Python files using:

   ```bash
   python factorial.py
   python fibonacci.py
   python student.py
   ```

*Note: Replace the filenames with your actual filenames if they differ.*

## 🎯 Learning Objectives

* Understand the conversion of C code into Python.
* Learn basic Python syntax and programming logic.
* Practice loops, variables, functions, and conditional statements.
* Understand dictionaries and key-value pairs.
* Learn formatted output using f-strings.
